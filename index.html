01 / File infection

Virus

A malicious program that attaches itself to legitimate files and needs the infected file to be opened or run to spread.

How it spreads

It relies on human actions. It attaches to an executable file or document and can be passed along when someone shares, opens, or runs that infected file.

Effects

It can corrupt, modify, or permanently delete files.

Real-life scenario

Tom downloads a free game skin from a random forum as an .exe file. After he runs it, a virus secretly affects his school essays and family photos, leaving some files unable to open.

Prevention

✓Avoid suspicious downloads.
✓Check the file extension before opening it.
✓Keep antivirus protection active and updated.
02 / Self-replicating network threat

Worm

A self-replicating type of malware that travels independently across networks without needing a host file or human interaction.

How it spreads

It moves automatically across networks. It can exploit software bugs or security gaps to copy itself from one connected machine to another.

Effects

It can congest network bandwidth and drain system memory.

Real-life scenario

Tom uses a shared school computer to print a report. A worm copies itself onto his USB drive. When he connects it to his home PC, it spreads to that computer and may try to reach other devices on the home network.

Prevention

✓Restart your computer if instructed by trusted IT support.
✓Enable your firewall.
✓Turn on automatic software updates.
03 / Disguised software

Trojan horse

A harmful program disguised as legitimate, useful software. It tricks users into running it so it can compromise security.

How it spreads

It uses social engineering. It does not self-replicate; instead, it tricks people into downloading and installing it by pretending to be a useful program, media file, or system update.

Effects

It can create backdoors for attackers and steal sensitive data.

Real-life scenario

Tom downloads a free cheat tool for a PC game from a website. The tool appears to work, but a hidden Trojan horse is also running malicious activity in the background.

Prevention

✓Download software from official stores and websites.
✓Avoid offers that seem too good to be true.
✓Check carefully before opening or installing a file.
04 / Data held hostage

Ransomware

Malware designed to deny access to a computer system or data until money is demanded.

How it spreads

It often spreads through social engineering. A person may be tricked into downloading something disguised as a game, video, or important update.

Effects

It can lock or encrypt files so they cannot be opened, then display a demand for payment to restore access.

Real-life scenario

Tom downloads a game cheat tool that seems to work. Hidden ransomware then locks his school projects and photos, and a message demands $500 to get the files back.

Prevention

✓Keep your operating system and apps updated.
✓Back up important files regularly.
✓Avoid opening suspicious links or attachments.
Stay alert / stay protected
